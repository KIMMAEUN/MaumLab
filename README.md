# 마음톡 연습실 (MaumLab)

특수교육대상 중·고등학생을 위한 사회정서학습(SEL) **소통역량 연습 웹앱**입니다.
협력 보드게임 「우리 동네 한 바퀴」의 상황 카드 72장과 짝을 이루며, 카드의 QR을 찍으면 같은 번호 상황으로 바로 열립니다.

- 바로 쓰기: https://kimmaeun.github.io/MaumLab/
- 상황 바로 열기: 주소 뒤에 `#s1` ~ `#s72`
- 차시별 혼자 연습: `#solo1`, `#solo2`, `#solo3`

## 특징
- 설치·로그인 없이 태블릿 브라우저에서 바로 실행
- 1·2·3단계 상황 72개, 기분 15가지, 음성 읽기, 도움 카드
- 학생 기록은 **그 기기의 브라우저에만** 저장되며 서버로 전송되지 않습니다

## 파일
- `index.html` : 웹앱 전체 (파일 하나로 동작)
